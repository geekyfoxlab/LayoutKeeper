## 已观察到的问题

### 1. 无标题普通窗口被后续原生校验拒绝（CC Switch 实例）

现象：恢复预览可以识别窗口，执行却提示：

```text
Window selector changed since confirmation
```

已确认的代码缺陷：Swift 匹配层支持唯一无标题主窗口，但原生移动校验把标题和文档字段同时为空直接判成失败。
“普通窗口可见”和“辅助功能接口能返回非空标题”不是同一件事；没有证据证明这是多个窗口或额外权限导致的。

已有改动：在保留进程、窗口 ID、归属、窗口类型等校验的前提下，允许已确认的空标题、空文档组合通过一致性检查。
新增原生选择器和窗口归属测试。本地构建 38 曾记录该应用三次自动跨桌面恢复并回读成功。
这只证明当时该场景通过，不能推广为所有应用均通过。

### 2. 拔屏后 Chrome 漏恢复，重新保存后下一次能恢复

2026-11-06 00:43 的记录显示：窗口 token 未换，保存的标题与当前标题不同；仅内屏恢复重新按保存的内容匹配，结果需要确认，自动模式没有执行。
00:44 重新保存布局后，保存的标题更新，后续该窗口成功恢复。

已确认的流程缺口：外屏恢复有运行时窗口身份辅助，而仅内屏恢复主要使用保存文件中的语义选择器。
窗口内容变化时，标题会变化；标题变化不等于原窗口已关闭。这解释了重新保存为何会暂时改善该情况。

构建 40 的未实测改动：复用现有 RuntimeWindowIdentity（token 与进程启动时间），将确定匹配过的保存项在内存中关联到当前窗口。
缓存按显示配置及保存版本区分，保留保存的目标桌面和位置；不把运行时 ID 写进普通布局文件。
没有按 Chrome、Cursor 或 CC Switch 增加专用恢复名单。

限制：缓存只在当前 LayoutKeeper 进程中存在，首次建立关联仍依赖原匹配逻辑。
重启后标题已变化、多个窗口无法唯一匹配等情况，不能声称已解决。此实现尚未通过真实连续插拔验证。

### 3. Cursor 已识别，但移动前被拦截（根因未确定）

2026-11-06 00:47 的日志摘要（省略窗口标题、真实 token 和个人路径）：

```text
plan-item: state=ready match=title moveSpace=true auto=yes
execute auto: runnable=8 crossSpaceEnabled=true permits=8 blocked=0
Cursor: state=blocked pinned=true after{sp=- frame=-}
detail="写入前窗口或桌面改变，没有写入此窗口"
restore auto windows=8 [blocked=1,verified=7]
```

确定事项：该窗口匹配成功，存在跨桌面移动许可；失败发生在写入前，尚未派发移动，不是“系统已执行移动但窗口不动”。
同轮另外七个窗口回读通过。此前另一次 Cursor 恢复曾成功。

尚不能确定的事项：旧日志没有记录究竟哪个复核条件失败，不能断言是标题、文档字段、短暂读不到、桌面、几何或身份变化。
事后对静态窗口进行了 41 次只读观察，结果稳定；这不能解释或排除插拔时的瞬时变化。
不能把该问题归因于用户权限、软件有多个窗口或用户操作错误。

构建 40 的诊断改动：写入前分别报告身份、标题、文档、主窗口标识、窗口状态、快照匹配数、桌面和几何不一致，并保存当时读到的窗口状态。
对读不到窗口或快照短暂漏读最多尝试三次；真实身份或位置变化仍阻止写入。
保留原有回滚、撤销语义。该改动不代表已经查明或修复 Cursor 的根因。

### 4. 插拔后侧栏选中项未随当前配置切换

已有改动：配置 key 改变时选择对应屏幕；仅刷新同一配置时保留用户正在查看的其他布局。
构建 39 曾观察到接回外屏后选中对应配置；没有完整记录该构建双向插拔的侧栏验收，不标记为全面通过。

### 5. 测试版同名条目、反复要求辅助功能授权

本地构建使用临时签名；二进制更新后旧授权可能不再适用。曾多次更换测试名称，且有一次更新未先清理旧测试授权，造成授权条目混淆。
这是测试部署管理问题，不能据此解释所有窗口恢复失败。

构建时的原始警告：

```text
warning: signing identity 'LayoutKeeper Self-Signed' not found in the keychain; signing ad-hoc (updates will need the Accessibility permission re-granted)
```

最终使用固定测试名称、路径和 bundle ID；构建 40 启动前已用系统工具清理旧测试授权。
停止开发后的本地清理包括退出测试版、移除测试应用及其注册、测试授权、测试偏好和缓存。
正式安装的应用和共享的用户布局不属于测试缓存。
